# 🎤 قَلِّدْهَا - Aledha (لعبة التقليد الصوتية المصرية)

لعبة حفلات جماعية أونلاين (1-8 لاعبين) مستوحاة من لعبة Mimic Party بنكهة وأجواء مصرية شعبية أصيلة.
اسمع الصوت، شغل المايك، وقلده.. والذكاء الاصطناعي هيحكم بينك وبين صحابك!

---

## 🚀 التشغيل السريع (Quick Start)

الخادم يعمل حالياً على المنفذ 3001:
👉 افتح المتصفح على: **`http://localhost:3001`**

لتشغيل المشروع محلياً في أي وقت:
```bash
npm run dev
```

---

## 🎛️ المميزات الرئيسية

1. **محرك تحكيم ومقارنة صوتية بالذكاء الاصطناعي (Audio Similarity Engine):**
   - مطابقة ريتم الصوت والوقفات الديناميكية (RMS Energy Envelope عبر خوارزمية DTW).
   - مطابقة النغمة والانحدار الترددي (Spectral Centroid / Pitch Contour).
   - التمييز بين النغمات والتشويش والخشونة (Spectral Flatness / Noise Ratio).
   - درجات تقييم مصرية كوميدية:
     - ٩٠-١٠٠%: *نسخة طبق الأصل! 🔥*
     - ٧٠-٨٩%: *جامد فشخ! 👌*
     - ٤٠-٦٩%: *مش بطال، بس حاول تاني 😂*
     - ٠-٣٩%: *إيه ده يا فنان؟! 💀*

2. **لعب فوري ضد روبوتات ذكية (Solo / Bots Mode):**
   - إمكانية اللعب الفردي الفوري دون الحاجة لانتظار لاعبين آخرين بضغطة زر واحدة ضد روبوتات مصرية كوميدية ("أبو حميد القهوجي"، "سوسن الفرفوشة"، "عم شكشك").

3. **أصوات مدمجة ومحاكي تركيبي متكامل (Web Audio Synthesizer):**
   - اللعبة تعمل فوراً وتولد ١٠ أصوات مصرية أصيلة حتى لو لم تضع أي ملفات MP3 خارجية:
     - 🛺 توك توك بيكركر في حارة
     - 🐱 قطة بلدي بتنوء الساعة ٣ الفجر
     - 🚐 كلاكس ميكروباص السلام رمسيس
     - 🥖 بتاع الفينو في الحارة
     - ☕ تكتكة معلقة شاي القهوجي في الخمسينة
     - 🎹 تفريد أورج شعبي في فرح بلدي
     - 🦆 بطة بلدي مفجوعة
     - 🚑 سرينة إسعاف الدائري
     - 🦟 ناموسة الصيف
     - 🪚 منشار المعلم زكي النجار

4. **إضافة أصوات مخصصة بسهولة:**
   - ضع أي ملف صوتي بصيغة `.mp3` أو `.wav` في مجلد `public/sounds/` وعدّل ملف `src/data/sounds.json`.

5. **واجهة أركيد حماسية مصرية:**
   - دعم كامل للغة العربية (RTL) مع خط Cairo الحديث.
   - راسم ذبذبات حي للميكروفون (Live Waveform Visualizer).
   - منصة تتويج الفائزين ثلاثية الأبعاد (3D Podium) مع قصاصات الاحتفال (Confetti).
